A lightweight, zero-dependency foreign exchange currency converter that fetches live forex rates and provides instant bidirectional conversions across 150+ global currencies.

---

## ✨ Features

- **Live Exchange Rates**: Dynamically queries currency exchange APIs for up-to-date conversion rates.
- **Dynamic Country Flags**: Automatically syncs national flags based on selected ISO currency codes.
- **Bidirectional Swap**: One-click currency swapping with automatic recalculation.
- **Zero Framework Bloat**: Pure vanilla JavaScript with DOM optimizations and responsive CSS.

---

## 🚀 Quickstart

```bash
git clone https://github.com/Nikhil-Vzo/Currency-converter.git
cd Currency-converter

# Open index.html directly or run a local server:
npx serve .
```
